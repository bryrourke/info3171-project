Data Brushing

Brush Selection

Data brushing allows users to select a specific region of a chart. Selected data points are highlighted while unselected data points are visually de-emphasized.

Brush States

State Description
Default All data points are displayed normally.
Selection A translucent rectangle identifies the selected area.
Highlight Selected data uses the brand purple colour.
Unselected Data outside the selected area uses reduced opacity.
Reset Clearing the brush restores the original chart.

Brush Styling

  • Selected Data: Brand purple (#3B118D).
  • Unselected Data: Brand purple with 25% opacity.
  • Brush Area: Pastel purple (#E1CBF6).
  • Selection Border: Brand magenta (#B21665).
HTML Pattern
<svg viewBox="0 0 600 300">
  <rect class="ctv-brush-selection"
        x="215" y="30" width="250" height="210" />

  <rect class="ctv-brush-selected"
        x="245" y="70" width="45" height="170" />

  <rect class="ctv-brush-unselected"
        x="85" y="150" width="45" height="90" />
</svg>
CSS Pattern
.ctv-brush-selection {
  fill: #E1CBF6;
  fill-opacity: 0.5;
  stroke: #B21665;
  stroke-width: 2;
  stroke-dasharray: 5 3;
}

.ctv-brush-selected {
  fill: #3B118D;
}

.ctv-brush-unselected {
  fill: #3B118D;
  opacity: 0.25;
}
