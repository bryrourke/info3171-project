Form Inputs

Text Input

Allows users to search or filter dashboard data by entering text.

HTML Pattern
<label for="video-search">Search Videos</label>
<input type="text" id="video-search"
       class="ctv-input" placeholder="Enter video title" />

Dropdown

Allows users to select a category or time period to update chart data.

HTML Pattern
<select class="ctv-input">
  <option>All Time</option>
  <option>Last 7 Days</option>
  <option>Last 30 Days</option>
  <option>Last 90 Days</option>
</select>

Radio Buttons

Allows users to select one chart style from multiple options.

Chart Style
HTML Pattern
<label>
  <input type="radio" name="chart-style" value="default" checked />
  Default
</label>

<label>
  <input type="radio" name="chart-style" value="alternate" />
  Alternate
</label>

Checkboxes

Allows users to enable or disable multiple chart display options.

Display Options
HTML Pattern
<label>
  <input type="checkbox" checked /> Show Labels
</label>

<label>
  <input type="checkbox" checked /> Show Legend
</label>

<label>
  <input type="checkbox" /> Show Grid Lines
</label>
CSS Pattern
.ctv-input {
  padding: 10px 12px;
  border: 1px solid #11268D;
  border-radius: 8px;
  background: #FEFAFB;
  color: #11268D;
}

.ctv-input:focus {
  outline: 2px solid #B21665;
  outline-offset: 2px;
}

input[type="radio"],
input[type="checkbox"] {
  accent-color: #B21665;
}
