Buttons

Primary Button

Used for primary actions such as applying filters or updating charts.

HTML Pattern
<button class="ctv-btn-primary">Filter Data</button>
<button class="ctv-btn-primary">Apply</button>

Secondary Button

Used for secondary actions such as resetting filters or cancelling changes.

HTML Pattern
<button class="ctv-btn-secondary">Reset</button>
<button class="ctv-btn-secondary">Cancel</button>

Disabled Button

Used when an action is temporarily unavailable.

HTML Pattern
<button class="ctv-btn-primary" disabled>Download</button>
CSS Pattern
.ctv-btn-primary {
  background: #B21665;
  color: #FEFAFB;
  border: 1px solid #B21665;
  padding: 8px 16px;
  border-radius: 8px;
}

.ctv-btn-primary:hover:not(:disabled) {
  background: #78118D;
  border-color: #78118D;
}

.ctv-btn-secondary {
  background: transparent;
  color: #B21665;
  border: 1px solid #B21665;
  padding: 8px 16px;
  border-radius: 8px;
}

.ctv-btn-primary:disabled {
  background: #D9D9D9;
  color: #777777;
  border-color: #D9D9D9;
  cursor: not-allowed;
}
