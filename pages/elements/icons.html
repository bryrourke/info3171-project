Icons

Dashboard Icons

Icons provide visual indicators for common dashboard actions. They should be simple, consistent, and easy to recognize.

Icon Usage

Icon Usage
Search Find specific data.
Filter Filter chart data.
Zoom In Explore chart details.
Zoom Out Reduce chart scale.
Reset Restore default settings.
Download Export dashboard data.

Icon Guidelines

  • Default icon size: 24 × 24 pixels.
  • Default icon colour: #11268D.
  • Action icon colour: #B21665.
  • Use consistent stroke widths.
  • Provide accessible labels for icon-only buttons.
HTML Pattern
<button type="button" aria-label="Search">
  <svg class="ctv-icon" viewBox="0 0 24 24"
       fill="none" stroke="currentColor" stroke-width="2"
       aria-hidden="true">
    <circle cx="10" cy="10" r="6" />
    <path d="M14.5 14.5L21 21" />
  </svg>
</button>
CSS Pattern
.ctv-icon {
  width: 24px;
  height: 24px;
  color: #11268D;
  stroke-linecap: round;
  stroke-linejoin: round;
}

.ctv-icon:hover {
  color: #B21665;
}
