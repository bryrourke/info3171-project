3.2 Grid Configuration

A 12-column CSS Grid provides a consistent alignment system. On desktop and tablet screens, each KPI occupies four columns and each detailed chart occupies six. Mobile cards span all 12 columns.

Pattern Columns Spacing
KPI card 4 of 12 24 px desktop / 16 px smaller
Chart card 6 of 12 24 px desktop / 16 px smaller
Full-width card 12 of 12 Optional for wider charts
Card padding — 16 px
Card radius — 8 px

CSS pattern

.ctv-grid { display: grid; grid-template-columns: repeat(12, minmax(0, 1fr)); gap: 24px; }
.ctv-kpi { grid-column: span 4; }
.ctv-chart { grid-column: span 6; }
.ctv-full { grid-column: 1 / -1; }
.ctv-card { min-width: 0; padding: 16px; border-radius: 8px; background: #fff; color: #11268D; box-shadow: 0 2px 8px rgba(59, 17, 141, 0.12); }

/* KPI background colours */
.ctv-kpi:nth-child(1) { background: #CBE1F6; }
.ctv-kpi:nth-child(2) { background: #CBCBF6; }
.ctv-kpi:nth-child(3) { background: #E1CBF6; }

/* Chart accent colours */
.ctv-chart:nth-child(3n+1) { border-left: 5px solid #3B118D; }
.ctv-chart:nth-child(3n+2) { border-left: 5px solid #B21665; }
.ctv-chart:nth-child(3n) { border-left: 5px solid #78118D; }

3.3 Responsive Screen Sizes

The layout adapts to the viewport rather than relying on fixed chart widths. Smaller screens stack cards vertically so that content remains readable without page-level horizontal scrolling.

Viewport KPI per row Charts per row Gap
Desktop ≥ 1200 px 3 2 24 px
Tablet 768–1199 px 3 2 16 px
Mobile < 768 px 1 1 16 px
CSS pattern
@media (max-width: 1199px) {
  .ctv-grid { gap: 16px; }
  .ctv-main { padding: 16px; }
}
@media (max-width: 767px) {
  .ctv-kpi, .ctv-chart { grid-column: 1 / -1; }
  .ctv-header { flex-wrap: wrap; }
}
